# LumiZoom — draft outreach messages

These drafts are for review before posting. They describe the project factually and do not ask for artificial stars, reviews, or downloads.

## Short English description

LumiZoom is a free, open-source live screen magnifier for Windows, designed for people with low vision. It provides a consistent full-desktop zoom, cursor highlighting, configurable hotkeys, and a lightweight interface for everyday computer work. The project is available in the Microsoft Store and on GitHub:

https://github.com/lumizoom-project/LumiZoom

Feedback from people who use screen magnification in everyday Windows workflows is especially welcome.

## Suggested issue for testers

If you use LumiZoom, please report your Windows version, display scaling, approximate hardware age, and whether the Start menu and other system menus remain readable while zoomed. Do not include personal or sensitive information.
