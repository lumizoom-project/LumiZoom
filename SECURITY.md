# Security / Bezpieczeństwo

Please do not publish security vulnerabilities as public issues. Report them to **lumizoom.project@gmail.com** with steps needed to reproduce the problem.

Prosimy nie publikować luk bezpieczeństwa jako publicznych zgłoszeń. Należy przesłać je na adres **lumizoom.project@gmail.com**, dołączając sposób odtworzenia problemu.
