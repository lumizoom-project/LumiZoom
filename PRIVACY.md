# Privacy policy

[Polski](PRIVACY.pl.md) · **English**

LumiZoom operates locally on the user's computer.

- It does not collect or transmit personal data.
- It contains no telemetry, analytics or advertising.
- It does not require registration or an online account.
- Application settings are stored locally in the current user's Windows registry.
- Network access is not required for magnification. A web browser or mail application is opened only when the user explicitly selects the project link or contact address.

Questions: lumizoom.project@gmail.com
