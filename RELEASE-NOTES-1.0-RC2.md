# LumiZoom 1.0 RC2

## English

The second public release candidate of LumiZoom is easier to install and ready for wider Windows 10/11 testing.

### [Download the Windows installer](https://github.com/lumizoom-project/LumiZoom/raw/refs/heads/main/dist/LumiZoom-1.0-RC2-Setup.exe)

### Changes

- self-contained Windows x64 installer — no separate .NET installation required;
- Windows startup enabled by default on first launch;
- automatic selection of a supported Windows display language, with English fallback;
- corrected project link;
- all functionality from RC1 retained.

## Polski

Drugi publiczny kandydat do wydania LumiZoom jest łatwiejszy w instalacji i gotowy do szerszych testów na Windows 10/11.

### [Pobierz instalator Windows](https://github.com/lumizoom-project/LumiZoom/raw/refs/heads/main/dist/LumiZoom-1.0-RC2-Setup.exe)

### Zmiany

- samowystarczalny instalator Windows x64 — bez potrzeby osobnej instalacji .NET;
- autostart domyślnie włączony przy pierwszym uruchomieniu;
- automatyczny wybór obsługiwanego języka interfejsu Windows, z angielskim jako językiem zapasowym;
- poprawiony link do projektu;
- zachowane wszystkie funkcje RC1.
