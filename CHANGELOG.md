# Changelog / Historia zmian

## 1.0.0 RC2 — 2026-09-11

### English

- Self-contained Windows x64 build; a separate .NET installation is no longer required.
- Windows startup is enabled by default on first launch.
- The application automatically uses a supported Windows display language and falls back to English.
- Corrected the project link to `https://github.com/lumizoom-project/LumiZoom`.

### Polski

- Samowystarczalna wersja Windows x64; osobna instalacja .NET nie jest już wymagana.
- Autostart z Windowsem jest domyślnie włączony przy pierwszym uruchomieniu.
- Aplikacja automatycznie wybiera obsługiwany język interfejsu Windows, a w pozostałych przypadkach używa angielskiego.
- Poprawiono adres projektu na `https://github.com/lumizoom-project/LumiZoom`.

## 1.0.0 RC1 — 2026-08-21

### English

- First public release candidate.
- Full-screen animated magnification and pointer tracking.
- Configurable shortcut, zoom, animation and cursor highlight.
- Light, dark and system themes with three UI font sizes.
- Multilingual interface and accessible tray operation.
- Standard Windows installer with upgrade, running-process and uninstall support.

### Polski

- Pierwsza publiczna wersja kandydująca.
- Animowane powiększanie całego ekranu i śledzenie kursora.
- Konfigurowalny skrót, poziom zoomu, animacja i podświetlenie kursora.
- Motyw jasny, ciemny i systemowy oraz trzy wielkości czcionki.
- Wielojęzyczny interfejs i obsługa z zasobnika systemowego.
- Standardowy instalator Windows z aktualizacją, kontrolą uruchomionego procesu i odinstalowaniem.
