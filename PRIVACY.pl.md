# Polityka prywatności

**Polski** · [English](PRIVACY.md)

LumiZoom działa lokalnie na komputerze użytkownika.

- Nie zbiera ani nie przesyła danych osobowych.
- Nie zawiera telemetrii, analityki ani reklam.
- Nie wymaga rejestracji ani konta internetowego.
- Ustawienia programu są przechowywane lokalnie w rejestrze Windows bieżącego użytkownika.
- Powiększanie nie wymaga internetu. Przeglądarka lub program pocztowy są otwierane wyłącznie wtedy, gdy użytkownik sam wybierze odsyłacz do projektu albo adres kontaktowy.
