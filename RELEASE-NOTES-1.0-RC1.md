# LumiZoom 1.0 RC1

## English

This is the first public release candidate of LumiZoom — a free, open-source live screen magnifier for Windows, designed for people with low vision and older computer users.

The installer includes the application, Start menu and desktop shortcuts, uninstall support, and the local UIAccess certificate configuration required for correct mouse interaction while magnified.

Download:

- [Windows installer](dist/LumiZoom-1.0-RC1-Setup.exe)
- [ZIP package](dist/LumiZoom-1.0-RC1-Setup.zip)
- [SHA-256 checksums](dist/SHA256SUMS.txt)

Supported systems: Windows 10 and Windows 11, 64-bit. This is a release candidate intended for testing before version 1.0.

## Polski

To pierwszy publiczny kandydat do wydania LumiZoom — bezpłatnej lupy ekranowej o otwartym kodzie dla Windows, przeznaczonej dla osób słabowidzących i starszych użytkowników komputerów.

Instalator zawiera aplikację, skróty w menu Start i na pulpicie, obsługę odinstalowania oraz konfigurację lokalnego certyfikatu UIAccess potrzebnego do prawidłowego klikania podczas powiększenia.
